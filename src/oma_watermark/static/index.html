使用帮助

打开图片后，在左侧原图上框选水印区域，再点击「重新处理」。默认使用 AI 精修，复杂背景通常比快速模式更自然。

选区

选区尽量贴近水印，并留一点边缘余量。选区越准确，修复越自然。

阈值与扩展

水印没清干净时调低亮度阈值；出现白边或阴影时调大边缘扩展。扩展越大，修复区域越大。

模式选择

快速 · OpenCV 适合纯色、简单背景；AI 精修 · LaMa 更适合衣物、地面、纹理等复杂背景。

首次使用 AI 精修，请先运行 uv run oma-watermark-download-model。

结果与检测

处理完成后，在右侧切换「结果 / 检测」。「检测」会用红色标出本次被修复的像素。

隐私

图片只在本机的本地服务中处理，不经过第三方服务。
